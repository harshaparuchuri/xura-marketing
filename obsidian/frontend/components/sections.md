# Catalog — Sections

Files in `src/components/sections/` — full-width page bands composed into views
under `src/views/`. **Home order (2026-11-15, ADR-0035):** `HomeHero → Statement → PlatformTeam (#how-we-deploy) → EmployeesGrid (#ai-employees) → IndustriesTabs → PulseBand → Bootcamp (#bootcamp) → Faq → HomeClosing → SiteFooter`, all from `sections/home/`, copy in `src/data/home.ts`. Seven sections modelled on wonderful.ai's structure, monochrome, few words, big surfaces. `HomeHero` is full-viewport on a dark `FlowField` with `<SiteNav overDark />`. `Statement` (server) is a dark `FlowField` band: label + a short two-line statement + kicker + "See how we deploy" on the left, and `ApprovalFeed` on the right (grid children `min-w-0` so the feed's truncated rows can't widen the column on phones). The earlier silk texture / dot grid / typing chips were removed for looking like a copy of wonderful.ai. Theme rule: reuse old-site elements if useful, but recoloured to monochrome. `PlatformTeam` = two large cards (app screenshot / abstract field) + inline steps + MIT stat. `EmployeesGrid` has two parts: an open roster in the live site's layout (72 px expressive monochrome `AiOrb`, name in light 3xl, mono role, bold job + one line; no card boxes), then "What they produce" — a scroll rail with one card per output type (order 2026-11-19: Answers, Apps, Dashboards, Research reports, Audience tests, Pulse reports, Decks, Social posts, Briefs, Infographics, Simulated personas) (`HOME_OUTPUTS` in `data/home.ts`, owner 2026-11-18): Answers first (the coded `AskXuraPreview` chat), Apps (the coded `HiringAppPreview` at 200% width scaled 50%), Audience tests (Xura Pulse, the coded `PulseLivePreview` at 200% scaled 50%), Pulse reports (`PulseReportPreview`), Simulated personas (`PulseInterviewPreview`), Dashboards, Decks, Social posts (`out-social.webp`, a real LinkedIn post, 1080×1350), Research reports, Briefs (`out-brief-overview.webp`, page 1 of a real “Business Operations Overview” PDF brief, 1654×2339), Infographics, with `RailNav` + right-edge fade. The cards are the shared `sections/shared/outputs-list.tsx` → `OutputsList` (also used by /platform's `OutputsRail`). Each output is drawn by `OutputShot` (same file): the crop's top-left is pinned to the area's top-left, the crop width spans the area, and the rest of the capture continues right and down so the 240 px area is always filled. The image area bleeds off the card's right and bottom edges (`pl-7`, `rounded-tl-2xl` only) — the owner prefers this offset look over an inset frame. `width`/`height` default to the 2880×1800 product captures. `Bootcamp` sits on a full-width `bg-line-soft` band; `Faq` is centred, single column. `IndustriesTabs` is a client leaf: pill tablist + one large panel. `Bootcamp` is one large light card + the trust line. `home/reveal.tsx` holds `Reveal` and `SectionHead`; `Faq` emits FAQPage JSON-LD. Photos (generated stand-ins from `public/assets/photos/`, see [[photo-brief]]) fill the hero, team card, industries tabs (cross-fade, home-only `PHOTO` map in `industries-tabs.tsx`), bootcamp right half and closing texture, each under a dark gradient + `.grain` where text sits on top. `SiteNav` takes `overDark`: `StickyHeader` sets `--nav-ink` / `--nav-paper` to white-on-ink until scroll, and nav links, logo and buttons read those vars (fallback foreground/background). Superseded 12-section order (2026-11-14, ADR-0033) used Problem, DeployBand, WhyXura, Employees, ChannelsBand, IndustriesGrid and Trust — those files were deleted. Previous home order (2026-10-04): `Hero → DomainsStrip → HowItWorks → Features → Recommendations → Agents → Outputs → Channels → XuraVs → Industries → EnterpriseReady → CaseStudy → ClosingCta → SiteFooter`. ## Industry pages

`src/views/industry.tsx` + `src/views/industries-index.tsx` compose the
`/industries/[slug]` and `/industries` routes. All copy comes from
[`src/data/industries.ts`](../../../src/data/industries.ts). Adding a new
industry: add a record with `slug`, `label`, `headline`, `problem`,
`useCases`, `scenario`, `cta` — the route and nav pick it up automatically.
Each record also carries a `heroImage` (path under `/public/industries/`)
and `heroImageAlt` — the solution band on `industry.tsx` renders this as a
duotone-treated `next/image` (2026-08-10; replaces the previous `Duotone`
placeholder). The same image is used by the home carousel
([[#Sections and bands|`industries-carousel.tsx`]]).
Screenshot slot: `data-slot="industry-<slug>-solution"` (now wrapped around
the real photograph).
